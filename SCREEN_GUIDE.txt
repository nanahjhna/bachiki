BACHIKI 화면 구성 및 기능 안내
==============================

1. 파일 구성 트리

lib/
├─ main.dart                         앱 시작, 테마, 전체 라우트 등록
├─ models/
│  └─ stage_model.dart               스테이지 데이터 모델
├─ services/
│  ├─ stage_generator.dart           스테이지 자동 생성 규칙
│  └─ user_session.dart              로그인 방식 기기 저장/조회/로그아웃
├─ utils/
│  └─ app_texts.dart                 한국어/영어/일본어 문구 및 즉시 언어 갱신 알림
├─ widgets/
│  ├─ ad_banner_widget.dart          배너 광고 표시 영역
│  └─ game_bottom_navigation.dart    공통 하단 메뉴
└─ screens/
   ├─ loading_view.dart              시작 로딩 후 타이틀 자동 이동
   ├─ title_view.dart                시작, 로그인, 설정, 상점 진입
   ├─ login_view.dart                Google/Apple/게스트 로그인 방식 선택 및 저장
   ├─ account_link_view.dart         계정 연동 관리 화면
   ├─ main_screen.dart               로비/인벤토리/상점/캐릭터/설정의 탭 컨테이너
   ├─ lobby_tab.dart                 재화, 스테이지 전투, 퀘스트/공지 바로가기
   ├─ main_lobby_view.dart           이전 로비 샘플 화면(현재 메인 흐름에서는 미사용)
   ├─ stage_select_view.dart         무한 스테이지 목록, 잠금 및 보상 표시
   ├─ game_play_view.dart            보스 HP, 타이머, 공격 및 일시정지 게임 루프
   ├─ pause_overlay.dart             재개, 설정, 로비 포기 메뉴
   ├─ result_view.dart               승패, 보상, 재도전, 로비 복귀
   ├─ character_view.dart            캐릭터 소개/스킬/능력치/퍽, 인벤토리 이동
   ├─ inventory_view.dart            일람형 아이템, 체크 선택, 착용/해제
   ├─ shop_view.dart                 상품 카드와 구매 진입 UI
   ├─ quest_view.dart                일일 퀘스트/업적 진행도 및 보상 수령
   ├─ notice_view.dart               공지 상세 펼치기와 7일 출석 보상
   └─ settings_view.dart             사운드, 계정 연동, 게스트 Google 연동, Google 로그아웃

2. 로그인 동작

처음 실행
  Loading → Title → TAP TO START → Login → Main

로그인 후 다시 실행
  Loading → Title → TAP TO START → Main

- Google 로그인: 설정에 '로그아웃' 표시. 로그아웃하면 다음 시작 시 로그인 선택 화면으로 이동.
- 게스트 로그인: 설정에 'Google 계정으로 연동' 표시.
- Apple 로그인: 현재 선택 방식을 유지해 자동 진입.
- 실제 Google/Apple 인증 SDK 연결 전에는 로그인 방식만 기기에 저장하는 샘플 동작.

3. 화면 이동 트리

[Loading]
  └─ [Title]
      ├─ TAP TO START ── 저장된 로그인 없음 → [Login] → [Main]
      │                  저장된 로그인 있음 → [Main]
      ├─ Settings → [Settings]
      └─ Shop → [Shop]

[Main: 공통 하단 메뉴]
  ├─ Lobby
  │   ├─ Stage Battle → [Stage Select] → [Game Play] → [Result]
  │   │                                  └─ [Pause Overlay]
  │   ├─ 번개 아이콘 → [Quest]
  │   └─ 공지 아이콘 → [Notice]
  ├─ Inventory
  ├─ Shop
  ├─ Character → Inventory 버튼 → [Inventory]
  └─ Settings → [Account Link], Google 연동 또는 로그아웃

[Stage Select], [Inventory], [Shop], [Character], [Settings]
  └─ 하단 공통 메뉴로 Lobby / Inventory / Shop / Character / Settings 전환

4. 공통 UI 규칙

- 게임 플레이를 제외한 게임 관리 화면은 하단 공통 메뉴를 사용한다.
- 자동 좌측 상단 뒤로가기 버튼은 제거한다.
- Main 화면의 지구본 아이콘에서 언어를 선택하면 앱 텍스트가 즉시 갱신된다.
- 화면별 실제 서버, 결제, 인증, Flame 엔진 연결은 현재 UI/흐름을 기반으로 추후 구현한다.
